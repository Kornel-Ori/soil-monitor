About Soil Monitor

Soil Monitor is an Internet of Things (IoT) project developed to monitor soil moisture levels using connected sensors and a Raspberry Pi.

The system collects soil moisture readings and sends the data to a FastAPI application, where readings are stored in a database and displayed on a dashboard.

Project Purpose

The aim is to help users monitor soil conditions, understand moisture changes over time and make better decisions about when plants need watering.

Internet of Things (IoT)

This project demonstrates how physical sensors, hardware, software and databases can work together. The Raspberry Pi collects data from the soil moisture sensor through an ADS1115 analogue-to-digital converter and communicates with the application.

Technologies Used

  • Raspberry Pi 5
  • Soil moisture sensor and ADS1115 ADC
  • Python
  • FastAPI
  • SQLite and SQLAlchemy
  • HTML, CSS and Bootstrap
